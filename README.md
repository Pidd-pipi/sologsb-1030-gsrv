# 飞行检查单编写与校验工具（sologsb-1030）

用于按飞行阶段编写、校验、复核和冻结操作检查单。项目实现完整的数据模型、本地持久化、版本控制、快捷键、拖拽排序、校验、修订差异与打印导出。

## 功能

- 角色权限（共享终端，越权即拒）：顶栏切换 **机长 / 复核员 / 资料员**。
  - 机长只维护检查项（挑战语、回应、关键标记、前置条件、顺序）；
  - 复核员只处理关键项签认、提交/退回复核与冻结；
  - 资料员只整理飞行阶段与项目资料；
  - 越权操作在数据层直接拒绝并弹出红色提示；撤销/重做同样受角色约束。
- 关键项签认与失效重算：
  - 关键项内容、顺序（含跨阶段/阶段排序）或前置条件任一改动，原签认立即失效并记录失效原因；
  - 按执行顺序自动重算“可执行批次”（相邻关键项归一批，连续签认前缀方可执行）；
  - 存在未有效签认的关键项时不能冻结，复核员可退回机长修改后重新确认。
- 冻结留痕：冻结快照保留阶段、检查项、提交/冻结角色署名、全部签认记录（含失效原因）；打印稿与独立 HTML 导出附关键项签认台账。
- 历史旧档：没有角色/签认信息的旧冻结记录自动标记为“历史旧档”，仅可只读查看与打印。
- 阶段与检查项：维护飞行阶段、挑战语、预期回应、关键标记、前置条件和异常处置。
- 快速录入：可使用 `/` 聚焦挑战语，`Cmd/Ctrl+Enter` 新增检查项，`Alt+↑/↓` 调整当前项位置。
- 拖拽排序：检查项可拖动并跨阶段移动，阶段也可调整先后顺序。
- 发布校验：
  - 重复挑战语与高频回应；
  - 缺少挑战语或预期回应；
  - 自引用、已删除或顺序不可达的前置条件；
  - 飞行阶段顺序异常；
  - 空阶段提示。
- 发布流程：编辑中 → 复核中 → 冻结；存在阻断错误或关键项签认不完整时不能提交复核或冻结。
- 修订控制：冻结后可由机长创建新修订（新修订签认需重新完成）；冻结快照保留阶段、检查项、角色与签认。
- 版本差异：可选择当前版本或任意冻结版本作为基准与比较版本，显示新增、删除、修改和阶段调整。
- 键盘与历史：支持撤销、重做（仅回退可编辑内容，不动角色签认与流程状态）、手动保存，最近 40 次编辑可回退。
- 离线保存：所有数据写入浏览器 `localStorage`。
- 只读预览与打印：提供对话框预览、浏览器打印/PDF，以及独立打印版 HTML 导出（保留角色、签认与失效原因）。

## 技术栈

- React 19
- TypeScript 5
- Radix Themes
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。宿主机正式端口由根目录 `docker-compose.yml` 映射为 `10030:80`，源码不硬编码宿主端口。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1030 .
docker run --rm -p 10030:80 sologsb-1030
```

多阶段镜像构建完成后由 nginx 监听容器 `80`，只提供静态前端资源。

## 数据说明

浏览器存储键为 `sologsb-1030-workspace-v1`，主题偏好使用 `sologsb-1030-theme`。当前版本内置 C172 示例检查单及两个历史冻结版本。
